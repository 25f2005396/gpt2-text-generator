# GPT-2 Text Generator

A simple AI-powered text generation application built using GPT-2, Hugging Face Transformers, and Gradio.

## About the Project

This project demonstrates how to use a pre-trained GPT-2 language model to generate text from user-provided prompts through an interactive web interface.

Developed as a hands-on learning project during the workshop **Getting Started with Hugging Face: Models, Datasets and AI Applications**, conducted as part of the IIT Madras BS Degree Programme.

## Technologies Used

- Python
- GPT-2
- Hugging Face Transformers
- Gradio
- PyTorch

## Features

- Accepts text prompts from users.
- Generates text using the pre-trained GPT-2 model.
- Displays generated text through an interactive Gradio interface.
